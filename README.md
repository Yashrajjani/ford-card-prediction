🚗 Ford Car Price Prediction

This project focuses on predicting the selling price of Ford cars using Machine Learning techniques. The goal is to build a regression model that can estimate a car's market price based on its specifications and historical data.

📌 Project Overview

The automotive industry generates a large amount of data related to vehicle pricing. Accurately predicting car prices helps buyers, sellers, and dealerships make informed decisions. In this project, Exploratory Data Analysis (EDA), data preprocessing, feature engineering, and regression algorithms were used to develop a predictive model for Ford car prices.

🎯 Objectives
Analyze the factors affecting Ford car prices.
Clean and preprocess the dataset for modeling.
Perform Exploratory Data Analysis (EDA) to identify patterns and relationships.
Train and evaluate multiple regression models.
Select the best-performing model for price prediction.
Save the final model for future deployment and use.
📂 Dataset Features

The dataset contains various attributes of Ford vehicles, including:

Model Name
Manufacturing Year
Transmission Type
Mileage
Fuel Type
Tax
Miles Per Gallon (MPG)
Engine Size
Selling Price (Target Variable)
🔍 Exploratory Data Analysis (EDA)

The following analyses were performed:

Missing value detection and treatment
Duplicate value checking
Statistical summary of numerical features
Distribution analysis using histograms
Correlation analysis using heatmaps
Outlier detection using box plots
Relationship analysis between features and car prices
⚙️ Data Preprocessing
Handled missing values and duplicates.
Encoded categorical variables.
Scaled numerical features when required.
Split the dataset into training and testing sets.
